# Local Development Setup Guide

## Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v18 or higher)
- **npm** or **yarn** or **bun**
- **Git**
- A code editor (VS Code recommended)

## Step 1: Export from Lovable to GitHub

1. In Lovable, click the **GitHub** button (top right)
2. Click **Connect to GitHub** and authorize the Lovable GitHub App
3. Select your GitHub account/organization
4. Click **Create Repository** to generate a new repo with your project code
5. Wait for the sync to complete

## Step 2: Clone the Repository

```bash
# Clone your repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git

# Navigate to project directory
cd YOUR-REPO-NAME
```

## Step 3: Install Dependencies

```bash
# Using npm
npm install

# OR using yarn
yarn install

# OR using bun
bun install
```

## Step 4: Configure Lovable Cloud Backend

This project uses **Lovable Cloud** (powered by Supabase) for backend functionality.

### Get Your Credentials

Your Supabase credentials are in the `.env` file (auto-generated by Lovable):
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_PROJECT_ID`

**Note:** The `.env` file should already exist in your cloned repo. If not, create it with the format above.

### Find Your Credentials in Lovable

1. In Lovable, go to Project Settings → Cloud
2. Your credentials will be displayed there
3. Copy them to your local `.env` file

### Alternative: Connect Directly to Supabase

If you want full control over your backend after your Lovable subscription ends:

1. Go to [supabase.com](https://supabase.com) and create a free account
2. Create a new project
3. Go to Project Settings → API
4. Copy your project URL and anon/public key
5. Update your `.env` file with these new credentials

**Important:** If you switch to your own Supabase project, you'll need to:
- Migrate your database schema (see `supabase/migrations/` folder)
- Migrate your data manually
- Deploy edge functions to your new project

## Step 5: Run the Development Server

```bash
# Using npm
npm run dev

# OR using yarn
yarn dev

# OR using bun
bun run dev
```

The app will be available at `http://localhost:5173` (default Vite port)

## Step 6: Configure Edge Functions (Optional)

If your project uses edge functions:

### Option A: Continue Using Lovable Cloud Edge Functions
- Your edge functions will continue to work as deployed
- You won't be able to deploy new functions without Lovable subscription

### Option B: Deploy to Your Own Supabase Project

1. Install Supabase CLI:
```bash
npm install -g supabase
```

2. Login to Supabase:
```bash
supabase login
```

3. Link your project:
```bash
supabase link --project-ref YOUR_PROJECT_ID
```

4. Deploy edge functions:
```bash
supabase functions deploy
```

## Step 7: Configure Secrets (If Needed)

If your project uses API keys or secrets:

1. In Lovable: Project Settings → Secrets → View your secrets
2. In your own Supabase: Dashboard → Edge Functions → Manage Secrets
3. Add each secret using the Supabase CLI:

```bash
supabase secrets set SECRET_NAME=secret_value
```

## Common Issues & Solutions

### Issue: "Supabase client error" or "Connection refused"
**Solution:** Check that your `.env` file has the correct credentials

### Issue: Database queries failing
**Solution:** Run migrations in your Supabase project:
```bash
supabase db push
```

### Issue: Edge functions not working
**Solution:** Deploy them to your Supabase project (see Step 6)

### Issue: Authentication not working
**Solution:** Configure auth providers in Supabase Dashboard → Authentication → Providers

## Maintaining Two-Way Sync with Lovable

While your subscription is active, changes sync automatically:
- Changes in Lovable → Push to GitHub → Pull locally
- Changes locally → Push to GitHub → Sync to Lovable

After subscription ends:
- You keep full access to your code via GitHub
- No more automatic sync with Lovable
- Continue development locally or deploy elsewhere
